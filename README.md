## 🚀 Fitur Unggulan Website:

- 🌟 **Desain Luxury & Responsif:** Menggunakan React 18, Vite, dan Tailwind CSS dengan palet warna Emerald, Gold, dan Slate Dark Mode.
- 🎁 **Banner Promo Super Deal 2026:** Menonjolkan promo **GRATIS BIAYA AJB, SHGB, dan BPHTB** serta unit siap huni berpaving dan berkanopi.
- 🏠 **Interactive Unit Showcase (Tipe 30+ & Tipe 36+):** Tab interaktif untuk melihat render eksterior 3D, denah berwarna, dan spesifikasi teknis bangunan lengkap.
- 📐 **CAD Blueprint Viewer:** Zoom modal resolusi tinggi untuk meneliti gambar kerja arsitek dan rincian dimensi setiap ruangan.
- 🎬 **Video Tour & Masterplan:** Pemutar video native untuk tur lingkungan cluster dan tata letak kawasan (Central Park, Ruko, One Gate Security).
- 📍 **Aksesibilitas Strategis:** 1 Menit ke Bundaran Barelang, 2 Menit ke Top 100 Tembesi, 2 Menit ke RS Awal Bros, dsb.
- 🧮 **Kalkulator Simulasi KPR Real-Time:** Slider dinamis untuk mengatur harga unit, persentase DP, tenor tahun, dan suku bunga bank dengan tombol konsultasi WhatsApp otomatis.
- 📅 **Formulir Booking Survey Lokasi:** Memudahkan calon pembeli memilih tanggal survey show unit yang langsung terhubung ke WhatsApp marketing.
- 🏢 **Profil Pengembang CIPTA Group:** Menguatkan kepercayaan dan legalitas hukum sertifikat properti.
- 💬 **Floating WhatsApp:** Tombol chat melayang dengan tooltip pengingat promo.

## 🛠️ Menjalankan Project:

### 1. Jalankan Development Server:
```bash
npm run dev
```
Buka browser di: `http://localhost:5173`

### 2. Build untuk Produksi:
```bash
npm run build
```

### 3. Preview Hasil Build:
```bash
npm run preview
```
